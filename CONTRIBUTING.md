# Contributing

Thanks for helping out!

- **Translations:** see [docs/translations.md](docs/translations.md). You can do it on the GitHub website.
- **Bugs:** open an issue with your Minecraft and mod version, what happened, and the chat line involved, if any.
  For chat head problems, the exact chat message (copy it from `logs/latest.log`) helps a lot.
- **Code:** fork the repository and open a pull request. Run `./gradlew build` first (JDK 25); it runs the tests.
